# 🎬 Nexus-Collection

**Nexus-Collection** est une application moderne de gestion de collection de films et de livres. Elle permet de rechercher des œuvres, de gérer une liste de souhaits (watchlist) et de suivre sa progression.

---

## ✨ Fonctionnalités

- 🔍 **Recherche intelligente** : Intégration avec l'API TMDB pour trouver n'importe quel film.
- 📚 **Scan de livres** : Fonctionnalité de scan pour ajouter rapidement des livres à votre collection.
- 🔐 **Authentification** : Système de connexion sécurisé pour gérer votre espace personnel.
- 📱 **Interface Responsive** : Design fluide optimisé pour mobile et desktop.
- 🗄️ **Base de données robuste** : Gestion des données performante avec Prisma et PostgreSQL/SQLite.

---

## 🚀 Technologies utilisées

- **Framework** : [Next.js 15](https://nextjs.org/)
- **Langage** : TypeScript
- **Base de données** : Prisma (ORM)
- **Style** : Tailwind CSS
- **API** : TMDB (The Movie Database)
